# 🧹 System Cleaner

Небольшая утилита для очистки Windows 10/11. Освобождает место на диске C, чистит временные файлы, удаляет старые обновления, проверяет целостность системных файлов. Работает локально, без интернета.

## ✨ Что умеет

- 🗑️ Чистит временные папки Windows и пользователя
- 🌐 Удаляет кэш браузеров: Edge, Chrome, Яндекс, Opera, Firefox
- 🧺 Очищает корзину через системный Shell API
- 📦 Удаляет старые обновления Windows (WinSxS)
- 🔧 Проверяет целостность системных файлов (SFC, DISM)
- ⚡ Расширенная очистка диска (cleanmgr)
- 💤 Отключает гибернацию (по желанию)
- ⭐ Создаёт точку восстановления перед очисткой
- 📋 Ведёт журнал операций и хранит логи

## ⚙️ Быстрый старт

1. Скачайте `SystemCleaner.exe` по ссылке выше.
2. Положите файл на диск C или D (не на флешку, не в архиве).
3. Запустите двойным кликом, подтвердите запрос UAC.
4. Нажмите **Анализ**, потом **Очистить**.
5. Подробная инструкция — в PDF.

## 🔑 Активация

Пробная версия даёт **15 запусков**. После — потребуется лицензионный ключ.

1. Утилита покажет окно активации и ваш **HWID**.
2. Отправьте HWID продавцу.
3. Получите ключ и введите его в окне активации.
